## About

I build web portals and single-page apps for large-scale digital services. Since 2022 I've been a full-stack developer and front-end team lead at **DXC Technology**, responsible for code review, code quality and front-end architecture decisions.

My focus is the front end: **React, Next.js and Angular**, always in TypeScript. Behind it I work with **Spring Boot BFFs**, contract-first **OpenAPI**, **GraphQL** and OIDC sign-in through **Keycloak**, SPID and CIE. I also build with AI coding agents (Claude Code) and review their output like any other pull request.

## Selected work

**Digital wallet for citizens** · 2026<br>
Angular 21 SPA and Spring Boot 4 / Java 25 BFF, built contract-first on OpenAPI 3.1. The API client is generated from the contract and an ESLint rule forbids hand-written HTTP calls. CIE sign-in over OIDC, problem+json errors with correlation IDs, Kubernetes probes, accessibility checks with axe-core.

**Interoperability gateway portals** · 2025–2026<br>
Four Next.js 16 / React 19 portals with Tailwind CSS 4, Apollo GraphQL, Keycloak sign-in (SPID), next-intl and Swagger UI. Non-root Docker images built by Jenkins on Kubernetes, with BuildKit and SonarQube.

**Local public transport observatory** · 2024–2025<br>
My main project (~880 commits): a restricted Next.js 14 portal with Apollo GraphQL, next-auth + Keycloak, Leaflet maps and Chart.js dashboards, configured at runtime through the Docker entrypoint, plus its public counterpart.

**SPAs for administrative procedures** · 2023–2024<br>
Five React + TypeScript SPAs on a shared archetype, with OpenAPI-generated RxJS clients, react-hook-form, TanStack Table, Jest + Testing Library and multi-stage Docker builds with a SonarQube stage.
